# Research Apps

A simple directory of my research projects and interactive demos. Select a project for its source code and documentation, or open a demo to try it.

## State dynamics

- **State Dynamics Engine:** A simulation of 12 numbers that change over time. Repeat a run with noise, memory, or basin projection switched on or off to investigate what each mechanism does. Memory Weather uses a separate experimental engine.  
  **Demos:**
  - [State Dynamics Lab](https://donaldtuttle.github.io/state-dynamics-engine/simulator/)
  - [Memory Weather Lab](https://donaldtuttle.github.io/state-dynamics-engine/memory-weather-lab/)
  - [Compact Probe](https://donaldtuttle.github.io/state-dynamics-engine/simulator/probe.html) (State Dynamics Lab v1)
  - [Memory Weather](https://donaldtuttle.github.io/state-dynamics-engine/memory-weather/) (v1)

  **Source:** [GitHub repository](https://github.com/donaldtuttle/state-dynamics-engine)

## Memory

- **HME:** An experimental memory engine combining a shared numerical field with identifiable stored records. Explore how noisy clues affect retrieval and which stored items are returned. Decision Revision Bench is an illustrative fixture, not a connected HME experiment.  
  **Demos:** [HME Plate](https://donaldtuttle.github.io/HME/) · [Decision Revision Bench](https://decision-revision.grok.me/) ([source](https://github.com/donaldtuttle/HME/tree/main/demos/decision-revision))  
  **Source:** [GitHub repository](https://github.com/donaldtuttle/HME)

- **Braid Memory:** Experiments with matching later updates to their earlier source records, including comparisons against ordinary search. It uses synthetic histories; the linked hosted demo does not include all newer experiments in the repository.  
  **Demo:** [Braid Memory](https://hme-operator-braid-memory.grok.me/)  
  **Source:** [GitHub repository](https://github.com/donaldtuttle/braid-memory)
## Prompt and context

- **Context Engineer Workbench:** Give an AI reusable background material, ask follow-up questions, and inspect what was supplied on each turn. Its diagnostics include token usage and content hashes; hashes do not prove that the AI used the information correctly.  
  **Demo:** [Context Engineer Workbench](https://context-engineer-workbench.grok.me/)  
  **Source:** [GitHub repository](https://github.com/donaldtuttle/context-engineer-workbench)

- **Prompt Engineering Workbench:** A local tool for controlled comparisons between a baseline prompt, injected context, and a length-matched control. Saves inputs, hashes, and run records for inspection and replay. Runs on your computer, with an offline mock mode.  
  **Local setup and source:** [GitHub repository](https://github.com/donaldtuttle/prompt-engineering-workbench)

- **Three-Lane Probe:** Ask the same AI question three ways: normally, with added context, and with a length-matched control. It helps investigate whether differences come from the added information or simply a longer prompt; it does not score answer quality.  
  **Demo:** [Three-Lane Probe](https://cactus-umbra-vivid-lunar.grok.me/)  
  **Source:** [GitHub repository](https://github.com/donaldtuttle/three-lane-probe)

## Lattice

- **Lattice Dynamics Lab:** Watch a grid of connected numerical cells evolve under adjustable rules. Start from the same conditions, change one setting, and compare the resulting patterns.  
  **Demo:** [Lattice Dynamics Lab](https://donaldtuttle.github.io/lattice-dynamics-lab-/)  
  **Source:** [GitHub repository](https://github.com/donaldtuttle/lattice-dynamics-lab-)

## QOFT

- **QOFT Lab:** A small simulation of a numerical field on a two-dimensional grid. Compare runs with an optional phase-flip rule turned on and off to see how it changes the results.  
  **Demo:**
  - [QOFT Lab](https://donaldtuttle.github.io/qoft-lab/)

  **Source:** [GitHub repository](https://github.com/donaldtuttle/qoft-lab)

- **QOFT Calculus:** Turns a set of mathematical update rules into a repeatable 12-dimensional simulation. Inspect its behavior and disable individual mechanisms to see what changes. Some linked tools are separate implementations, so their results are not automatically comparable.  
  **Demos:**
  - [R12 Simulator](https://donaldtuttle.github.io/qoft-calculus/simulator/)
  - [Compact Probe](https://donaldtuttle.github.io/qoft-calculus/simulator/probe.html)
  - [Memory Weather](https://donaldtuttle.github.io/qoft-calculus/memory-weather/)
  - [Memory Weather Lab](https://donaldtuttle.github.io/qoft-calculus/memory-weather-lab/)
  - [QOSMOS R12](https://qosmos-r-12.grok.me/)
  - [Glyphogenic Calculus](https://glyphogenic-calculus.grok.me/)

  **Source:** [GitHub repository](https://github.com/donaldtuttle/qoft-calculus)
